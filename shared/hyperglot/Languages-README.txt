Languages.json is Cicero's export of Hyperglot 0.8.1 by Rosetta Type
(https://github.com/rosettatype/hyperglot), generated 2026-10-12 by
opr-inzn/cicero scripts/update-languages.py (commit bd25d2a).
Hyperglot is Apache License 2.0; see Languages-LICENSE.txt.

Cuttler uses it the way Cicero does: a font supports a language when one
primary orthography's base characters and required marks are all present.
Character coverage only. No shaping checks. Do not edit by hand.
